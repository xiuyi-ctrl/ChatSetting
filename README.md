# 对话拾页

本地运行的对话浏览器。支持上传 `.docx` 文档，或粘贴公开的 `https://chat.deepseek.com/share/…` 链接。Word 文档按 `A：` / `B：` 标记拆分，支持横线或空段落分隔；DeepSeek 链接按分享消息配对，并按 Markdown 格式显示回答及 LaTeX 公式。两种来源都保留可获取的图片。

推荐使用 [AB_conversation_template_v2.docx](AB_conversation_template_v2.docx)：每轮的 `A：` 和 `B：` 是独立、加粗、16 磅的固定样式段落，正文写在其下。复制整组标记和内容即可增加轮次。解析器会优先识别这种样式，避免把正文里的 A/B 格式示例误认作新轮次。

## 启动

在本目录执行：

```powershell
python server.py
```

然后打开 <http://127.0.0.1:8765/interface-sample.html>。可上传 Word 文件，也可在左下角粘贴 DeepSeek 分享链接并点击“导入链接”。每个来源显示在左侧工作空间，点击即可切换或删除；中间栏显示当前来源的轮次。支持轮次搜索、上一轮/下一轮和图片放大。若本地放有 `sample.docx`，首次打开页面时会显示该示例；它不会提交到仓库。

仅监听本机地址；上传内容在内存中解析，不写入服务器文件。浏览器会在本机保存导入结果和阅读位置，刷新页面后恢复；清除该站点的浏览器数据会移除这些记录。链接导入依赖 DeepSeek 当前公开分享接口；若来源限制访问或接口发生变化，页面会显示导入失败原因。
