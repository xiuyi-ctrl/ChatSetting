# 对话拾页

本地运行的对话浏览器。支持上传 `.docx` 文档，或粘贴公开的 ChatGPT / DeepSeek 分享链接。Word 文档按 `A：` / `B：` 标记拆分，支持横线或空段落分隔；分享链接按用户和助手消息配对，并按 Markdown 格式显示回答及 LaTeX 公式。Word 和 DeepSeek 来源保留可获取的图片；ChatGPT 分享消息中的图片若无法公开下载，会在所属轮次显示原分享页入口。

推荐使用 [AB_conversation_template_v2.docx](AB_conversation_template_v2.docx)：每轮的 `A：` 和 `B：` 是独立、加粗、16 磅的固定样式段落，正文写在其下。复制整组标记和内容即可增加轮次。解析器会优先识别这种样式，避免把正文里的 A/B 格式示例误认作新轮次。

## 启动

在本目录执行：

```powershell
python server.py
```

然后打开 <http://127.0.0.1:8765/interface-sample.html>。可上传 Word 文件，也可粘贴 ChatGPT / DeepSeek 分享链接并点击“导入链接”。每个来源显示在左侧工作空间，点击即可切换或删除；中间栏显示当前来源的轮次。支持轮次搜索、上一轮/下一轮和图片放大。若本地放有 `sample.docx`，首次打开页面时会显示该示例；它不会提交到仓库。

仅监听本机地址；上传内容在内存中解析，不写入服务器文件。浏览器会在本机保存导入结果和阅读位置，刷新页面后恢复；清除该站点的浏览器数据会移除这些记录。链接导入依赖两家服务当前的公开分享数据接口；接口可能变化，工作空间受限的链接也可能无法读取。

### 从 ChatGPT 分享页导入图片（电脑 Chrome）

普通链接导入无法读取需要登录的 ChatGPT 图片。使用本仓库的 `chrome-extension` 扩展，可以在你已登录的分享页尝试读取图片：

1. 重新启动 `python server.py`，并在 Chrome 打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本仓库的 `chrome-extension` 文件夹。
3. 在同一个 Chrome 中登录 ChatGPT，打开或刷新分享链接，确认页面里的图片已经显示。
4. 点击扩展图标，选择“导入当前分享页”。查看导入结果后，点击“打开对话拾页”。

扩展只在你点击按钮后读取当前分享页，并将该页对话与图片发送到本机 `127.0.0.1:8765`。它不会发送登录 Cookie。单张图片可先在分享页打开大图预览再导入；多张图片时扩展会按文件名依次尝试打开各张预览并分别截取，不会把一张预览重复填到多个位置。截取结果的分辨率以屏幕显示为准。若仍无法读取，图片会保留原分享页入口，扩展会报告未读取的数量。多图自动预览已用包含两张图片的分享链接在 Chrome 中验证；ChatGPT 页面结构变化后可能需要调整。

## Android APK

调试安装包位于 `android/app/build/outputs/apk/debug/app-debug.apk`。安装后可在手机上独立导入 Word 文档，或联网导入公开 ChatGPT / DeepSeek 分享链接，无需启动电脑上的 Python 服务。APK 不包含本地 `sample.docx`。目前为调试签名版本；正式发布需配置发布签名，并在真机验证文件选择、链接导入、图片和公式。

已安装 Android SDK 与 Gradle 时，在 `android` 目录运行 `gradlew.bat assembleDebug` 可重新构建。构建前会自动同步网页脚本、样式、公式资源和空白模板。
